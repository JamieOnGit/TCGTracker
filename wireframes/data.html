Data & API

Download our market cap, population and drops datasets, or query them with the public API. Free to use with attribution.

API /api/v1/

JSON REST API. Base URL https://BRAND/api/v1/. Auth: Authorization: Bearer <key>. OpenAPI spec: /api/v1/openapi.json.

MethodEndpointReturns
GET/api/v1/cardsSearch/list cards (?game, lang, set, q)
GET/api/v1/cards/{card_id}Card detail incl. external IDs
GET/api/v1/cards/{card_id}/market-capPop, floor, basis, market cap by grade
GET/api/v1/cards/{card_id}/historyPop & price history
GET/api/v1/sets/{set_id}Set detail + set market cap
GET/api/v1/rankingsRanked market cap (?game, lang, grade, page)
GET/api/v1/dropsDrop events (delayed 30 min unless Premium key)
curl -H "Authorization: Bearer $KEY" \
  https://BRAND/api/v1/cards/pkm-en-sv3pt5-199/market-cap
{ "card_id": "pkm-en-sv3pt5-199", "lang": "en", "grades": [
  { "grade": "PSA 10", "pop": 3412, "floor_aud": 4850, "basis": "last_sale", "market_cap_aud": 16548200 } ] }
