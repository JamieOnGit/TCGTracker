Clickable prototype for a Pokémon TCG & One Piece Card Game collector site (Australia). Four pillars: Market Cap, Marketplace, Drop Alerts, Data authority. Each page carries a dashed SEO annotation panel (real production URL, H1, title, meta, JSON-LD, indexability, canonical, internal links) and inline callouts explaining behaviour. Start at home.html. Resize to ≈390px to see mobile layouts.
